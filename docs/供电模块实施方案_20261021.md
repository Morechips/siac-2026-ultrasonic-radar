# 教育超声模块：5V输入供电模块实施候选

日期：2026-10-21。状态：器件资料与本机库名称已核对，以下是可照表接线的候选方案。**本轮未放置元件、未修改Proteus工程、未运行供电模型，也未完成实物电流或温升验收。** 供电实现前仍需确认元件模型属性及当前工程的隐藏电源映射。

采用外部已经稳压的名义5V直流电源，经保险丝、开关及反接保护后分成舵机5V和逻辑3.3V两路；不设计充电、电池管理或市电侧电路。已有测距、扫描、串口链路继续使用原固件。

## 1. 器件候选与本机库检查

本机只读检索路径为`D:\Proteus 8\Proteus 8 Professional\DATA\LIBRARY`。在`ANALOG.LIB`找到`LM1117MP-3,3`、`LM1117T-3,3`、`LM1117DT-3,3`等准确名称；`ANALOG.IDX`有对应LM1117说明。**找到库条目不代表已确认其SPICE模型绑定、引脚映射或运行结果。**

| 位号 | 本轮候选 | 用途与安装前确认 |
|---|---|---|
| U_PWR1 | TI LM1117MP-3.3/NOPB，SOT-223；库内名称`LM1117MP-3,3` | 首选3.3V固定输出；确认所选对象为可仿真器件，不能误选ADJ或5.0V版 |
| U_PWR1备选 | LM1117T-3.3，TO-220；库内名称`LM1117T-3,3` | 便于插接或散热的同功能备选，不与首选同时安装；具体可采购料号另核 |
| F_PWR1 | Bourns SF-1206S200-2，2A慢断保险丝 | 额定63VDC，标称冷阻0.041Ω、容差±25%；本机同名仿真条目未确认，不能声称熔断行为已模拟 |
| Q_PWR1 | Diodes DMP2035U-7，P沟道MOSFET，SOT-23 | 低压降反接保护候选；本机同名模型未确认，放置前核对模型/符号G/S/D，不默认通用PMOS能代替其参数 |
| SW_PWR1 | 两脚常开/常闭操作的SPST电源开关 | 实物额定至少3A DC、至少12VDC，接触电阻纳入压降预算；不得用信号按键代替 |
| LED_PWR1 | Kingbright WP710A10LID低电流红灯，或等效2mA指示灯 | 1.8kΩ限流，指示开关后电源；库内可用红色LED符号表达，实际型号与符号分别记录 |
| PSU1/J_PWR1 | 外部稳压5V、至少2A的成品低压电源及防误插两芯接口 | 电流为初选，实际舵机型号、负载峰值与保护后最低电压通过后才定型 |

LM1117固定版SOT-223为1=GND、2=OUT、3=IN、4/散热片=OUT。它额定可供800mA，但本方案逻辑负载预算仅150mA；输出电容需满足容量与ESR要求。依据[TI LM1117原厂手册，第3、5–6、14–15、18页](https://www.ti.com/lit/ds/symlink/lm1117.pdf)。保险丝参数依据[Bourns原厂手册](https://www.bourns.com/docs/product-datasheets/sf-1206s.pdf)；MOSFET引脚示意、导通电阻与额定值依据[Diodes原厂手册](https://www.diodes.com/datasheet/download/DMP2035U.pdf)。

本方案没有确认的保护器件模型不得被写成“已仿真保护”。若只能放通用符号，应在图上标为待绑定模型；理想电源、理想开关或等效电阻只能验证相应连接/压降，不能证明短路熔断或反接保护有效。

## 2. 网名及完整连接表

新增位号用`_PWR`，避免覆盖现有U1主控、U3 EEPROM及R1–R4上拉电阻。新增网名如下：

| 网名 | 定义 |
|---|---|
| EXT_5V | 外部电源正极，保险丝之前 |
| FUSED_5V | 保险丝之后、开关之前 |
| SW_5V | 开关之后、MOSFET漏极侧 |
| PWR_GATE | MOSFET栅极，仅接下拉电阻 |
| SYS_5V | 反接保护之后的公共5V输入干线 |
| SERVO_5V | SYS_5V从入口分出的舵机专用支路，与逻辑稳压支路分开走线 |
| LOGIC_3V3 | U_PWR1输出，逻辑器件及当前超声模型电源 |
| GND | 输入负极、各模块公共参考地；舵机大电流回路单独回到入口汇合 |

电源主路径为：`EXT_5V → F_PWR1 → FUSED_5V → SW_PWR1 → SW_5V → Q_PWR1(D→S) → SYS_5V`。

| 器件/引脚 | 连接到 | 参数及核对要点 |
|---|---|---|
| J_PWR1-1 / J_PWR1-2 | EXT_5V / GND | 本项目定义的两芯接口；实物插头的极性按电源核对，不凭线色判断 |
| F_PWR1-1 / F_PWR1-2 | EXT_5V / FUSED_5V | 2A慢断；保险丝没有极性 |
| SW_PWR1-1 / SW_PWR1-2 | FUSED_5V / SW_5V | SPST串在正极，不切断公共地 |
| Q_PWR1-D（SOT-23第3脚） | SW_5V | **漏极朝输入**，源极朝负载；正常接入时先经体二极管启动，再由沟道导通 |
| Q_PWR1-S（第2脚） | SYS_5V | 按D/S文字核对库符号；不可因习惯把S改到输入 |
| Q_PWR1-G（第1脚） | PWR_GATE | R_PWR1=100kΩ，从PWR_GATE到GND；该接法仅用于本方案5V输入 |
| C_PWR1 | SYS_5V正极到GND | 100µF/16V电解，电源分支入口储能初选 |
| SYS_5V分支A | SERVO_5V | 独立电源线去舵机，不经U_PWR1或MCU引脚 |
| C_PWR2 / C_PWR3 | SERVO_5V到GND | 舵机插座附近470µF/16V电解并100nF/16V以上陶瓷，均为初选 |
| J_SERVO-1 / -2 / -3 | GND / SERVO_5V / SERVO_PWM | 本项目接口约定；按所选实物舵机针序转换，不能假定全部舵机接口顺序相同 |
| U_PWR1-3（IN） | SYS_5V | 与输入电容正端同网 |
| U_PWR1-1（GND） | GND | 独立短回路接地 |
| U_PWR1-2及4/散热片（OUT） | LOGIC_3V3 | SOT-223散热片也是输出，不能当GND使用 |
| C_PWR4 / C_PWR5 | U_PWR1 IN到GND | 10µF/16V钽电容并100nF/16V以上陶瓷，靠近稳压器 |
| C_PWR6 | U_PWR1 OUT到GND | 22µF/10V钽电容初选，有效容量不少于10µF，ESR选择0.3–2Ω且在手册允许区间内 |
| R_PWR2 / LED_PWR1 | SYS_5V→1.8kΩ→LED阳极；阴极→GND | 电阻5%、1/8W或更高；LED不直接跨电源 |
| U1 VDD：7、15、23、32脚 | LOGIC_3V3 | 四个电源脚都接；每脚附近各一只100nF/16V X7R到GND |
| U1 GND：8、16、24、31脚 | GND | 四个地脚都接，不依赖示意图只画一个地符号 |
| U1 LDO：6脚 | C_PWR7=2.2µF/16V X7R到GND | 有效容量含容差和直流偏压后维持1–3µF；不接LOGIC_3V3，也不外供负载 |
| U3 24C02C：8脚 / 4脚 | LOGIC_3V3 / GND | 两脚之间就近100nF；A0/A1/A2及WP沿当前已确认接法，通常1/2/3/7脚到GND |
| R1/R2现有I2C上拉 | 由各自总线端经10kΩ到LOGIC_3V3 | PB2/33脚=SCL，PB3/34脚=SDA；上拉末端必须实际进入对应网络，不仅在图上靠近 |
| R3/R4现有按键上拉 | PB1/30脚、PB5/43脚各经10kΩ到LOGIC_3V3 | 按钮另一端接GND；只改供电归属时不要迁移GPIO或把按钮网直连3.3V |
| 本机SRF04模型VCC/GND | LOGIC_3V3 / GND | 当前模型1脚VCC、5脚GND，TRIG/ECHO沿现有接线；不把默认VCC/VDD改成5V |
| C_PWR8 | 超声模型/传感器电源到GND | 100nF/16V初选；实物成品模块若已有去耦应核对后去重 |
| TP1 / TP2 / TP3 / TP0 | EXT_5V / SYS_5V / LOGIC_3V3 / GND | 用于电压表/示波器测量，仪表两端都接好 |

LM3S317脚位和LDO电容依据[Luminary原厂手册，Arm/Keil官方存档，印刷384–393页](https://www.keil.com/dd/docs/datashts/luminary/lm3s317.pdf)。100nF就近去耦、储能电容和上述接线布局是本项目初选，不等于这些容量已经实测优化。PE0/35脚是GPIO，不能当作MCU供电脚。

若仿真电容为理想模型，可在C_PWR6电容支路内用0.47Ω串联电阻表达ESR：OUT→电容正极，电容负极→0.47Ω→GND。**该电阻只在电容支路，不串入3.3V主电源输出。** 实物选到ESR合适的钽电容后，不机械重复增加该电阻。不能直接用一只低ESR陶瓷替代LM1117要求的输出电容。

在Proteus中，现有VCC/VDD隐藏电源仍应归属3.3V逻辑网；舵机5V使用独立网映射。接入真实稳压模型时，检查是否仍有一个理想3.3V源并联在LOGIC_3V3上。若存在，它会掩盖稳压器掉压或断电问题；应在副本中确认电源驱动关系，不能仅靠同名标签判断。

## 3. 电流、电源容量与压降

以下全部是**设计假设，不是实测电流**。所选舵机未定型，暂用一只峰值不超过1.0A、允许4.8–6.0V的舵机作为预算对象。实际规格不符合时，重算本节，不用动画推断电流。

| 负载 | 预算 |
|---|---:|
| MCU及其I/O | 70mA |
| EEPROM写入 | 5mA |
| 超声传感器/模型预留 | 40mA |
| 四只10kΩ上拉同时拉低的上限 | 1.32mA |
| 3.3V其他余量 | 33.68mA |
| **3.3V合计上限假设** | **150mA** |
| 舵机峰值假设 | 1000mA |
| 稳压器静态电流预算 | 10mA |
| LED及栅极电阻 | 约2.1mA |
| **5V输入峰值预算，取整** | **1.17A** |

PSU初选名义5V/2A、带短路/过流保护的外部成品稳压电源；1.17A×1.25≈1.47A，向上取2A。这个余量不覆盖未知舵机的任意堵转电流；若实物峰值超过1A，必须重选电源、保险丝、开关和连接线。舵机电压/电流按真实型号核对，逻辑与舵机分支原则参见[Pololu厂家供电说明](https://www.pololu.com/docs/0J040/7.a)。

输入电压不能只看“5V”标签。LM1117-3.3完整电气规格的输入条件下限为4.75V；本候选以**U_PWR1 IN及SYS_5V最低不低于4.75V、最高不超过5.25V**作为供电验收门槛。单纯计算典型压差不替代该条件。[TI原厂手册](https://www.ti.com/lit/ds/symlink/lm1117.pdf)

压降示例：保险丝0.041Ω、MOSFET冷态0.035Ω、开关和连接线合计0.05Ω时，1.17A约降0.147V，输入端5.00V则SYS_5V约4.85V。考虑保险丝温升、MOSFET升温和接点变化，先以总串联电阻0.20Ω预算，压降约0.234V；输入端5.00V时仅剩4.77V，余量已经很小。**0.20Ω是待测预算，不是厂家保证的全链路最大值。**

因此，装配前应做到以下之一：

- 使用可调限流低压电源，先设5.10V，并确保峰值负载时J_PWR1处仍至少5.05V、SYS_5V至少4.75V；全程不超过实际舵机与接口允许值。
- 使用固定5V成品电源时，按实际线缆和峰值负载测量；只有通过SYS_5V最低电压门槛后才接纳。不能宣称任意5V±5%的适配器均满足，因为4.75V输入再减保护压降就超出LM1117的上述保证条件。

若无法满足，不串加肖特基二极管继续消耗压差，也不擅自升高固定电源；改选更低压差且模型/电容要求经核对的LDO，或降低回路电阻后重验。本文件优先本机1117库条目，不把尚未确定的新型号写成已定型器件。

Q_PWR1按最保守0.09Ω预算时，1.17A发热约0.123W；该电阻是给升温留余量的工程假设。保险丝是过流保护，不是精确的2A限流器；电源短路保护、保险丝熔断曲线和线材承载能力需配合确认。单只反接MOSFET也不是双向隔离，不能据此并接外部电源和USB电源。

反接保护仅按未带电系统的输入极性保护设计，更换电源先关SW_PWR1并等待储能电容放电；不做带电反接试验。该模块也未设计9V/12V误插的过压保护，J_PWR1必须明确标记仅接经核对的5V低压电源。

## 4. 电容、LED与散热核算

LM1117输入初选10µF；输出初选22µF钽电容，确保有效容量≥10µF且ESR满足0.3–22Ω，采购目标收紧为0.3–2Ω。容量、耐压和ESR都应写入BOM，不能只写“22µF”。[TI电容要求](https://www.ti.com/lit/ds/symlink/lm1117.pdf)

3.3V支路在VIN=5.25V、I_OUT=150mA、I_Q=10mA时，功耗近似`(5.25−3.3)×0.15 + 5.25×0.01 ≈ 0.35W`；再给输出误差留余量按0.36W预算。用TI小铜面积示例136℃/W估算，温升约49℃，环境40℃时结温约89℃。这是指定散热假设下的估计；洞洞板、封闭外壳和小转接板可能更差，仍需实测。不要把JEDEC板的61.6℃/W直接当作任意模块的热阻，也不能因为额定800mA就把本支路扩到800mA。[TI热设计表与布局说明](https://www.ti.com/lit/ds/symlink/lm1117.pdf)

低电流红灯WP710A10LID在2mA时典型V_F=1.7V，按5V、1.8kΩ估算约1.83mA。电阻选5%、1/8W；即使按LED短路估算，5.25V/1.71kΩ≈3.1mA，电阻功耗也不足17mW。指示亮度最终观察确认。[Kingbright原厂手册](https://www.kingbrightusa.com/images/catalog/spec/wp710a10lid.pdf)

舵机旁470µF只是储能初选。按`C=I×Δt/ΔV`，1A额外负载持续1ms且只许下降0.2V时，需要约5000µF；470µF只能对应约94µs。因此不能用“已加470µF”代替供电峰值验证，主要仍靠电源动态能力、连接线和回流布局。

## 5. 与现有仿真及实物的适配

当前超声模型继续按已经通过的3.3V配置；这不是实物SRF04的通用供电要求。厂家SRF04实物规格为5V、典型30mA，换实物时将其供电支路改为经核对的5V，并核查TRIG/ECHO接口。[厂家规格](https://www.robot-electronics.co.uk/srf04.html) LM3S317数字GPIO支持5V容忍，但移植其他主控时应重新核对具体管脚，不能直接沿用。MCU本身仍供3.3V。

本轮输入选外部稳压低压接口，**不采用裸USB-C插座直接取2A**。以后改USB供电时，应确认供电方通告/协商电流、接收端检测、线缆和限流能力；外形为USB-C并不等于允许2A。USB默认供电和Type-C 1.5A/3A通告是不同条件。[TI TUSB320原厂说明，7.3.2节](https://www.ti.com/lit/ds/symlink/tusb320.pdf) 实物USB转串口先只接信号和公共地，5V/3.3V输出不得直接并入此供电模块。

MOTOR-PWMSERVO若只表现CTRL动画，不能据此验收供电能力；MCU、EEPROM和传感器数字模型也可能不呈现实际运行电流，不能把其仿真读数当作峰值测量。可先用独立负载支路验证稳压：逻辑侧22Ω/1W约150mA；5V侧5Ω/10W约1A。两者均为**临时测试负载**，不作为正常工作器件计入模块BOM；1A脉冲/负载切换也只是设计验证，不冒充实物舵机电流测量。

## 6. 用户自行接线和测试的简短步骤

1. 保存当前能运行的工程，另开副本；先只搭输入、保护、稳压器及电容，不接MCU和舵机。核对固定3.3V型号、Q管D/S方向、电解极性、LDO脚用途与地线。
2. 核对隐藏电源和理想源没有绕过开关/稳压器；电压表两端分别接目标网与GND。上电先测EXT_5V、SYS_5V、LOGIC_3V3，逻辑输出应约3.3V且在MCU允许范围内。
3. 用22Ω测试逻辑负载、5Ω测试5V负载；记录输入/保护后/3.3V电压和电流。按先静态后切换负载顺序，检查SYS_5V最低≥4.75V及实际舵机电压要求。负载电阻发热按额定功率处理。
4. 断电移除测试电阻后接回MCU、EEPROM、超声和舵机；保留原引脚与固件，检查连续SCAN、按键、存储。观察扫描换向是否新增复位、卡住或串口中断。
5. 开关断开后确认负载侧逐渐放电，不能要求电容存在时立即归零；保存接线、各电压和至少10分钟仿真时间日志，并另记墙钟时长。真实舵机峰值、保护动作和实物温升另列实物待测，不以仿真无报错代替。
