## 2. 外设接线

### 2.1 超声模块 U2（SRF04）

模块引脚：`1=VCC，2=ECHO，3=TR，4=NC，5=GND`

| 模块脚 | 接到 | 说明 |
|---|---|---|
| 1 VCC | **3.3 V**（全局电源网 `VCC/VDD`） | 仿真必须 3.3 V；接 5 V 时模型不响应触发 |
| 2 ECHO | `US_ECHO` → PA3（20脚） | 模块输出 → MCU 输入 |
| 3 TR | `US_TRTG` → PA2（19脚） | MCU 输出 → 模块输入 |
| 4 NC | 悬空 | |
| 5 GND | `GND` | |

### 2.2 存储 U3（24C02C，8 脚）

| 芯片脚 | 名称 | 接到 |
|---|---|---|
| 1 | A0 | **GND** |
| 2 | A1 | **GND** |
| 3 | A2 | **GND** |
| 4 | VSS | GND（隐藏电源） |
| 5 | SDA | `SDA` → PB3（34脚）；**10k 上拉到 3.3V** |
| 6 | SCL | `SCK` → PB2（33脚）；**10k 上拉到 3.3V** |
| 7 | **WP** | **GND**（接高则写保护，写入无效） |
| 8 | VCC | 3.3V（隐藏电源） |

设备地址：A0=A1=A2=0 → 写 `0xA0`，读 `0xA1`。

### 2.3 舵机 SERVO1

| 舵机端 | 接到 |
|---|---|
| CTRL | `SERVO_PWM` → PB0（29脚） |
| VCC | **5 V** |
| GND | 共地 |

PWM：50 Hz（20 ms 周期），高电平 1.0~2.0 ms 对应 0°~180°。

### 2.4 按键（3 个）

每个按键一套：`引脚 ── 10k ── 3.3V`；`引脚 ── 按键 ── GND`。

| 按键 | 网络名 | MCU 脚 | 功能 |
|---|---|---|---|
| 按键1 | `BUTTON1` | PB1（30脚） | 启动 / 停止扫描 |
| 按键2 | `BUTTON2` | PB5（44脚） | 扫描速度切换（10 档，按住连续变化） |
| 按键3 | `BUTTON3` | PB4（43脚） | 回放 EEPROM 中存储的 31 条记录 |

上拉电阻：R3（BUTTON1）、R4（BUTTON2）、R2（BUTTON3），均 10k 到 3.3V。

### 2.5 串口 P1（COMPIM）

**COMPIM 的引脚排列不是顺序的**，右侧从上到下依次为：

| 行 | 编号 | 名称 | 方向 | 本工程接法 |
|---|---|---|---|---|
| 1 | 1 | DCD | 输入 | 悬空 |
| 2 | 6 | DSR | 输入 | 悬空 |
| 3 | 2 | RXD | 输入 | 悬空 |
| 4 | 7 | RTS | **输出** | **悬空（绝不能接 U0TX）** |
| 5 | 3 | **TXD** | 输入 | **`U0TX` ← PA1（18脚）** |
| 6 | 8 | CTS | 输入 | 悬空 |
| 7 | 4 | DTR | 输出 | 悬空 |
| 8 | 9 | RI | 输入 | 悬空 |

属性必须为：

```
{P_PORT=COM32}
{P_BAUDRATE=9600}
{P_DATABITS=8}
{P_PARITY=NONE}
{P_STOPBITS=1}
{P_SOFTFLOW=0}
{P_HARDFLOW=0}
{V_BAUDRATE=9600}
{V_DATABITS=8}
{V_PARITY=NONE}
{V_STOPBITS=1}
{V_SOFTFLOW=0}
{V_HARDFLOW=0}
```

### 2.6 虚拟终端

| 终端脚 | 接到 |
|---|---|
| RXD | `U0TX` |
| TXD / RTS / CTS | 悬空 |

设置：9600、8 数据位、无校验、1 停止位、不反相、不勾回显。

## 3. 电源

| 网络 | 电压 | 供给对象 |
|---|---|---|
| `VCC/VDD` | **3.3 V** | LM3S317（隐藏）、24C02C（隐藏）、SRF04 VCC、按键与 I2C 上拉 |
| `VDD5V` | 5 V | 舵机 SERVO1 |
| `GND` | 0 V | 全部共地 |

> 原理图中的 `LM1117T-3` 电源模块为**实物设计图**，整组元件需勾选「不进行仿真」，其输出端子不得与 `VCC/VDD` 相连。

## 4. 固件对引脚的寄存器配置（用于交叉核对）

```
PA_AFSEL = 0x3      // PA0、PA1 交给 UART0
PA_DIR   = 0x6      // PA1、PA2 为输出；PA0、PA3、PA4、PA5 为输入
PA_DEN   = 0xF      // PA0~PA3 数字使能

PB_DIR   = 0x5      // PB0(舵机)、PB2(SCL) 为输出；PB3 由 DIR 动态切换
                    //   释放 SDA：PB_DIR=0x05；驱动 SDA 低：PB_DIR=0x0D
PB_PUR   = 0x32     // PB1、PB4、PB5 内部上拉（模型可能未实现，故外部另加 10k）
PB_DEN   = 0x3F     // PB0~PB5 数字使能

UART0    : 9600 8N1, IBRD=52, FBRD=5（8 MHz）
Timer0   : 32 位自由运行，8 ticks/µs
```

> 重要：掩码 GPIO 访问返回的位仍在原位上，单引脚读取必须 `(reg >> 位号) & 1`；
> 掩码写入只有掩码对应位有效，拉高 PB2 要写 `0x04` 而不是 `1`。

---

## 5. 关键约束（核对时重点看这几条）

1. **SRF04 的 VCC 必须是 3.3 V**。接 5 V 时触发脚读数正常但 ECHO 全程不动（已实测）。
2. **MCU 的 TX 必须接 COMPIM 的第 5 行（编号 3，TXD）**，接第 4 行（编号 7，RTS）会导致该网络被 COMPIM 输出顶死、恒为低电平。
3. **SDA、SCL 各需要 10k 上拉到 3.3V**。缺上拉时 EEPROM 自检会读回 `00`（空片应为 `FF`）。
4. **24C02C 的 WP（7脚）必须接 GND**，否则地址应答正常但写入不生效。
5. **A0/A1/A2 必须全部接 GND**，否则设备地址不是 `0xA0`，EEPROM 不应答。
6. **COMPIM 的硬件流控必须关闭**（`P_HARDFLOW=0`、`V_HARDFLOW=0`），否则数据被扣住不发。
7. 所有地必须共地；舵机 5V 与逻辑 3.3V 分开供电。
