# V12 runtime：自己测试四步

适用：`LM3S317_radar_v12_runtime`，固件启动行含 `LM3S317_RADAR_V12`。当前用户反馈测距、扫描与网页正常，按键尚未确认。本文是操作步骤，不代表这些项目已通过。

助手后续只在后台修改文件、运行检查；用户有空时操作 Proteus，不需要一直配合。

## 开始前

若仍停在“另存为”对话框，可点“取消”回到原工程；不必为测试保存新名称。不要覆盖 `LM3S317_radar_v11_working.pdsprj`。确认 Proteus 正在运行，网页使用浏览器串口、9600、COM33；COMPIM 使用 COM32，同一 COM 口不能同时被串口助手占用。

网页“暂停展示”只冻结画面，不能用于证明硬件按键启停正常。需要看原始数据时，打开网页“连接与数据”中的日志，或看 Proteus Virtual Terminal。网页日志只保留最近80行，开机报错可能被后续SCAN挤掉；查看启动报错需要从重新运行时观察。

## 1. 测距和网页跟随

将超声模块的 Distance/SETPOINT 依次设为50cm、100cm（可用模型交互控件，或停仿真后改属性再运行）。

- 原始串口应分别出现约 `SCAN,...,500,OK,PROTEUS` 和 `SCAN,...,1000,OK,PROTEUS`。
- 网页应显示50.0cm、100.0cm，并随扫描改变角度。
- 模型距离由SETPOINT设定，舵机转动不会自行计算周围物体；等距圆弧是预期模型行为。

## 2. 按键1启停

按住按键1，直到Proteus底部仿真时间至少前进约1秒，再松开。电脑负载较高时，墙钟1秒不一定等于仿真1秒。

- 第一次应输出 `INFO,STOP`，随后不再产生新的SCAN；舵机应保持当前扫描方向。
- 再按一次应输出 `INFO,RUN`，SCAN恢复。
- 持续按住应只切换一次；松开后下一次按下才能再次切换。

若没有切换，看周期性 `BTN`：松开应为 `BTN,PB1=1,PB5=1`；按键1按住时PB1应变0。短按可能未碰到低频诊断行，因此要持续按住到出现诊断行。PB1是30脚；PB5是43脚，44脚是PB4。

## 3. 存储与按键2回放

EEPROM是图中的24C02C，用于保存最近31条样本，供历史回放，不参与实时测距显示。先让扫描运行至少40条SCAN；再用按键1停止采样，并确认已出现STOP，最后按键2。

预期顺序：

```text
INFO,REPLAY_START
LOG,采集序号,角度,距离mm或NA,状态
...
INFO,REPLAY_END
```

已有31条有效保存记录时应回放31条；刚启动、记录不足或记录被识别为损坏时可以少于31条。网页应标“历史测距/历史回放”，结束后仍保留历史标记。之后按键1恢复采样，新SCAN使网页回到实时。

若按键1本来就不通，按键2没有反应不能直接证明EEPROM坏了。先观察按键2持续按住时PB5是否变0。

## 4. 失败时留这几项信息

无需长报告，只记下工程名、启动BOOT版本及如下结果：

| 项目 | 填写 |
|---|---|
| 50/100cm跟随 | 正常 / 异常 |
| 按键1按住后的BTN | PB1=__，PB5=__ |
| STOP/RUN是否出现 | __ |
| 按键2按住后的BTN | PB1=__，PB5=__ |
| 是否出现REPLAY_START、LOG、REPLAY_END | __ |
| EEPROM错误的完整一行 | __ / 未观察到 |

特别留意 `INFO,EEPROM_ERR,VERIFY_MISMATCH`：表示写后读回的数据不一致。当次V12会将存储置为离线，但扫描可以继续正常。仅见 `INFO,EEPROM_READY,0` 表示启动恢复到0条有效记录，不能单独证明成功写入或芯片为空。

重启保留要另测，并记录Proteus是否配置了EEPROM映像保存；不能将模型重启等同于实物掉电验证。
