# 声探：课堂实验记录台

本轮新增网页功能，不需要更换HEX或修改Proteus接线。沿用[网页启动方式](../showcase/README.md)，在页面下方找到“我的实验记录台”。

## 一次课堂活动

1. 选择“近远与回声”“角度与方向”或“没有可靠回声”。
2. 在“先猜一猜”中写一句预测，可以留空。
3. 完成一次测量，在“准备记录的一笔”中确认距离、方向、状态和来源，再点“记录当前测量”。每次点击只记录一笔，不自动收集整段串口流。
4. 改变条件再记录，展开“分组比较”查看有效距离的平均、最小和最大值。
5. 结束前点击“导出CSV”，用Excel/WPS或文本编辑器打开。CSV保留全部记录，网页表格只显示最近8笔。

记录只存在当前页面内存中，最多200笔。刷新或关闭页面会丢失，先导出再离开；满额后拒绝新增，不会静默覆盖旧记录。清空需要在页面内再确认一次；“清空结果”只清雷达展示，不清实验记录。

## 不接串口也能做的三项实验

### 近远与回声

先用现有分步教学观察“定位→发射→回波→更新”，声波动画为慢放示意。随后打开“连接与数据”选择“字符串输入”，逐条应用以下教学数据，每次应用后关抽屉并记录一笔：

```text
SCAN,1,90,500,OK,SIM
SCAN,2,90,1000,OK,SIM
```

预测：远处目标的回声回来得更快还是更慢？两笔结果分别50cm、100cm。网页记录台只保存距离等输入字段；没有把距离反算成“实测回波时间”。教学过程中的时间计算是公式示意。

### 角度与方向

分别应用并记录：

```text
SCAN,3,0,850,OK,SIM
SCAN,4,90,850,OK,SIM
SCAN,5,180,850,OK,SIM
```

三笔都是85cm，方向分别向右、向前、向左。提问：只知道距离，能不能确定目标在哪里？不要一次应用三行后连点三次记录，那会记录三遍最后一笔。

### 没有可靠回声

分别应用并记录：

```text
SCAN,6,90,850,OK,SIM
SCAN,7,90,NA,TIMEOUT,SIM
SCAN,8,90,3000,OK,SIM
```

第二笔超时，第三笔超过250cm展示量程，两者都显示“—”。第三笔会保留“超展示量程”标记。无可靠距离能作为观察记录保存，CSV距离格为空，统计不会把它当0参与平均。

这些手动数据均标SIM，是教学输入，不是传感器实测。Proteus实测可在“浏览器串口”中改变Distance/SETPOINT后记录；当前模型不会随舵机角度自动计算周围声场。

## 记录和统计的含义

- **输入方式**：内置模拟、字符串输入或浏览器串口。
- **声明来源**：输入中的SIM、PROTEUS或DEVICE。手动填写PROTEUS并不能证明来自电路，因此输入方式也同时保存。
- **实时/历史**：LOG记录始终标历史，SCAN是非历史输入。历史记录可用于比较，不能作为当前障碍判断。
- **网页记录时间**：点击记录时的时间，CSV使用UTC；不是设备采样时间，也不用于测量声波传播耗时。
- **分组统计**：按输入方式、声明来源和实时/历史分别统计，只计算OK且有有效距离的记录；不混合求平均，不计算测距精度或教学效果。

暂停展示、最新测量帧无效或没有结果时禁止记录。实时串口断开或超过2秒没有新样本时，保留画面也不能作为当前测量记录；INFO/BTN诊断不会延长样本有效时间。明确标记的历史记录可以在断开串口后记录。

## 本版检查边界

自动检查覆盖CSV格式、来源隔离、无效距离、200条上限、样本快照及记录条件，另执行TypeScript和生产构建。没有为本版操作Proteus、浏览器或COM口，实际按钮点击、下载以及两种投屏尺寸仍待人工核验。硬件检查按[自己测试四步](自己测试四步_20261021.md)进行。
