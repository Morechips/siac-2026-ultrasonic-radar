# 供电模块设计

日期：2026-10-21。目标：给主控、EEPROM、超声模块、舵机设计一条可核算的供电链路，补上"完整应用"的电源部分。

## 1. 拓扑

```
外部 5V 适配器 / 充电宝
        │
     [SW-SPST]  电源开关
        │
     [FUSE]    保险丝 1A
        │
     ┌──┴───────────────────────────┐
     │ 5V 母线                       │
     │                              │
   [LED-RED + 470Ω] → GND        舵机 VCC（5V 直供）
     │                              │
   [LM1117T-3] 3.3V LDO
     │  输入 10µF ── GND
     │  输出 22µF ── GND
     │
  3.3V 母线
     ├─ LM3S317 VDD（含 100nF 去耦）
     ├─ 24C02C VCC（含 100nF）
     └─ 超声模块 VCC（仿真中 3.3V，见 §5）
        │
     全部 GND 共地
```

## 2. 元件清单（Proteus 中可直接搜到）

| 器件 | Proteus 搜索名 | 参数 | 作用 |
|---|---|---|---|
| 电源开关 | `SW-SPST` | — | 总电源通断 |
| 保险丝 | `FUSE` | 1A | 过流保护 |
| 电源指示 | `LED-RED` + `RES` | 470Ω | 上电指示 |
| 稳压器 | `LM1117T-3` | 3.3V / 800mA | 5V → 3.3V |
| 输入电容 | `CAP` | 10µF | LDO 输入储能 |
| 输出电容 | `CAP` | 22µF | LDO 稳定性（LM1117 要求 ≥22µF 钽/低 ESR） |
| 去耦电容 | `CAP` | 100nF ×2 | MCU、EEPROM 就近去耦 |
| 电源端子 | `POWER` | VCC/VDD=3.3V、VDD5V=5V | 走线用 |

## 3. 电流预算（设计计算，非实测）

| 负载 | 典型 | 峰值 | 供电轨 |
|---|---|---|---|
| LM3S317 @ 8MHz | 25 mA | 40 mA | 3.3V |
| 24C02C 写入 | 3 mA | 3 mA | 3.3V |
| 超声模块 SRF04 | 15 mA | 15 mA | 3.3V（仿真）／5V（实物） |
| 舵机（空载） | 100 mA | — | 5V |
| 舵机（堵转/换向） | — | **700 mA** | 5V |
| 电源指示 LED | 6 mA | 6 mA | 5V |

- **3.3V 支路合计**：约 43 mA 典型 → LM1117 轻松胜任
- **5V 支路合计**：约 106 mA 典型，**堵转时约 800 mA**
- **电源适配器选型**：5V / **1A 以上**（堵转留余量），不能只按空载 100mA 选

## 4. 稳压器核算

| 项 | 数值 |
|---|---|
| 输入 | 5.0 V |
| 输出 | 3.3 V |
| 压差 | 1.7 V > LM1117 最小压差 1.1 V ✔ |
| 3.3V 侧电流 | ≈ 45 mA |
| LDO 功耗 | (5.0 − 3.3) × 0.045 ≈ **77 mW** |
| 结温估算 | 77 mW × 约 60 ℃/W ≈ 升温 5 ℃，无需散热片 ✔ |

**如果把舵机也接到 3.3V**：堵转 700 mA × 1.7 V ≈ **1.2 W**，LDO 会过热保护甚至损坏 —— 这就是舵机必须直挂 5V 的原因，写进说明书是加分项。

## 5. 关于超声模块的电压（必须写清）

| 环境 | 模块供电 | 依据 |
|---|---|---|
| **Proteus 仿真** | **3.3 V** | 本机 SRF04/HCSR04 模型接 5V 时不响应触发（已实测） |
| **实物** | **5 V** | 厂家 SRF04/HC-SR04 规格要求 5V |

实物状态下还有一条：**ECHO 是 5V 输出，不能直连 LM3S317 的 3.3V 引脚**，需分压（如 1k + 2k）或电平转换。仿真中模块供 3.3V，输出电平自然是 3.3V，不存在这个问题。

> 说明书建议写法：仿真按模型要求供 3.3V；实物按器件规格供 5V 并增加 ECHO 电平适配，两者差异已记录。

## 6. 在 Proteus 中怎么搭

### 推荐做法：画在主工程里，但设为不参与仿真

把电源模块画在主工程的空白处，**整组元件勾选「不进行仿真」**，图纸上可见、仿真里不存在。

理由：

- 主工程现在由全局理想电源轨（VCC/VDD = 3.3V、VDD5V = 5V）供电，真实稳压器一旦进网表，会激活**模拟求解器**：仿真变慢，且可能再次触发 `[SPICE] {null}` 一类启动失败
- 勾掉仿真后，元件只作为图形存在，截图、讲解、评阅都不受影响，风险为零

操作：

1. 按 §6.1 画出电源链，输出端用一个独立端子（如 `3V3_REG`），**不要**接 `VCC/VDD`
2. 逐个选中该组元件 → 右键 **Edit Properties** → 勾选 **「不进行仿真」**
3. 旁边放一段文字说明（见 §6.2）

### 6.1 接线

```
5V源(BATTERY/DC) ──[SW-SPST]──[FUSE 1A]──┬── LED-RED ── 470Ω ── GND
                                          │
                                          ├── 5V 母线 ── 舵机 VCC
                                          │
                                          └── LM1117T-3 ── 3.3V 母线(3V3_REG)
                                               输入 10µF → GND
                                               输出 22µF → GND
                                               └─ 超声模块 VCC
```

仿真中的实际供电（供对照，不要改）：

- MCU、EEPROM、超声模块：全局 `VCC/VDD` = 3.3V
- 舵机：`VDD5V` = 5V

### 6.2 应放在图纸上的说明文字

```
【电源模块 · 实物设计】
仿真采用 Proteus 理想电源轨供电（VCC/VDD = 3.3V，VDD5V = 5V）；
本模块为实物制作方案，不参与仿真。
设计要点：舵机 5V 直供，逻辑经 LM1117-3.3 降压至 3.3V；
电源容量按舵机堵转电流核算（≥1A），详见说明书供电章节。
```

### 6.3 备选：单独建电源工程

若希望电源链**真实带载**并测量各点电压，可另建 `LM3S317_power_module.pdsprj`：

1. 电压源 5V → 开关 → 保险 → LED 指示
2. `LM1117T-3` 输入接 5V 母线，输出接 3.3V 母线，输入 10µF、输出 22µF
3. 用假负载替代真实负载：3.3V 侧 68Ω（≈48mA）、5V 侧 6.8Ω（≈735mA，模拟舵机堵转）
4. 用电压表分别量 5V 与 3.3V 母线，填写 §7 的验收表

单独工程的好处是能实测；坏处是与主工程图纸分离，讲解时需要切换。

## 8. 需要写进说明书的结论

1. 舵机与逻辑**分轨供电**：舵机 5V 直供，逻辑经 LDO 变 3.3V
2. 电源容量按**堵转电流**核算（≥1A），不按空载
3. LDO 功耗 77mW，压差 1.7V 满足要求
4. 仿真与实物在超声供电上的差异已明确记录，实物需 ECHO 电平适配
