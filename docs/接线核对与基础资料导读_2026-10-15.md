# 接线核对与基础资料导读

日期：2026年10月15日。对象：Proteus8.9、STM32F103C6、UG-2864HSWEG01、HC-SR04。核对依据为用户截图、同日自动备份中的原理图导线/属性及厂家资料；未操作或更改用户原理图，未重新运行仿真。

## 一、本次结论：先改两只上拉电阻的接法

屏幕三个端子对应的GPIO选对了。当前R3、R4被串在了信号通路中，没有连接3.3V，不能提供I2C所需的上拉。

| SCL | PB6（42脚）经R3到AD5 | 端子对应正确，4.7k串联接法需改 |
| SDA | PB7（43脚）经R4到AD4 | 端子对应正确，4.7k串联接法需改 |

最新自动备份中的U1程序路径已为`..\sonar_edu\firmware\build\oled_gpio_diag.hex`，时钟属性`8MHz`，终端波特率`9600`。这些是文件属性核对，不代表程序或屏幕运行已经通过。

电源绑定读到：VDD、VDD3.3、VDDA→3.3V，VDD5V→5V，VSS、VSSA→GND，默认VCC→3.3V。隐藏电源脚实际指向的名称也需与这些绑定一致；“画了三角形”不等同于所有电源设置均正确。

## 二、现在具体怎样改

先停止仿真并保存副本，再操作：

1. 从SCL和SDA中间移走R3、R4，分别用普通导线补通原来的断口。
2. 确认PB6直接通到AD5，PB7直接通到AD4；两条信号彼此分开。
3. 将R3的一端接3.3V，另一端接到PB6—AD5这条信号线的分支点。
4. 将R4的一端接3.3V，另一端接到PB7—AD4这条信号线的分支点。
5. 从电阻引脚开始拉线，落在对应信号线上；检查分支处出现连接圆点。交叉但不相连的位置不要加圆点。
6. 保持PB5—IO4直连；这根复位线无需串入上述电阻。

最终电气关系：

| 网络 | 必须属于同一条导线网络的点 | 另接的电阻支路 |
|---|---|---|
| SCL | PB6、AD5 | 通过R3=4.7k接3.3V |
| SDA | PB7、AD4 | 通过R4=4.7k接3.3V |
| RESET | PB5、IO4 | 本测试无新增电阻支路 |

两只上拉电阻的电源端可以共用3.3V，信号端不能短接到一起。4.7k是本轮低速软件I2C测试的选值，实物电阻值还要结合速度、线长和总线电容核对。

## 三、为什么必须有上拉

当前固件把PB6/PB7配置为开漏输出。写低电平时，单片机把信号拉到地；写高电平实际是释放导线，需要上拉电阻把它带到3.3V。电阻放在信号通路中间而另一端没有电源，无法完成这件事。

这与LED的限流电阻不同：LED电阻串在电流通路里；I2C上拉电阻从信号线分支接到电源。TI资料第2页的Figure 1-1、NXP手册3.1.1节均可直接对照。[TI上拉电阻说明](https://www.ti.com/lit/an/slva689/slva689.pdf)，[NXP总线规范](https://www.nxp.com/docs/en/user-guide/UM10204.pdf)

## 四、OLED模型和实物要分别核对

当前AD4、AD5、IO4是原厂Arduino片段的端子名，不是F103的PA4、PA5或PB4，也不是让你换用Arduino。对应功能是SDA、SCL、RESET，当前F103固件使用软件I2C，PB6/PB7由本项目代码明确指定。

片段内部模式脚、数据总线保留原厂连线，本轮先验证显示协议。它简化了裸屏电源外围：实物中VDD逻辑电源和VCC显示驱动电源是两回事，不能按未命名电源符号把实物裸屏全部短接。当前片段与3.3V电网组合的实际显示仍待验收。

UG-2864HSWEG01裸屏与市售四针OLED小板不是同一层级的器件。前者要设计充电泵/参考电流等外围，后者通常已集成部分外围；实物采用什么电压，按所购小板的说明确定。

## 五、实物前需要补的两处

**ECHO到PA0：** 常规HC-SR04回波是5V逻辑。ST的F103C6引脚表中PA0没有FT（5V耐受）标记，不能把“多数IO耐5V”理解成PA0也耐5V。实物需分压或电平转换；当前直接连线的仿真结果不能证明实物可以直连。[ST引脚表](https://www.st.com/resource/en/datasheet/stm32f103c6.pdf)，[Adafruit模块引脚说明](https://learn.adafruit.com/ultrasonic-sonar-distance-sensors/pinouts)

例如两只10k相同电阻分压：ECHO经第一只接PA0，PA0再经第二只接地，5V理想分为2.5V；是否满足输入高电平还应对照ST数据手册，实际电阻误差和模块电平也要核对。此例来自模块供应商的3V接口接法，不要求现在把OLED测试和测距测试一起修改。

**D2：** LED须串入限流电阻；若仅作电源指示，可在3.3V支路中参考现有D1使用330Ω并核对电流，也可以直接删除D2辅助支路。不要把没有限流电阻的仿真亮灯接法抄到实物。

## 七、每次接新器件的自查清单

- [ ] 完整型号和封装对得上，确认看的是裸芯片、模块还是开发板。
- [ ] 根据引脚名及手册核对功能，不按图形左右位置或别人的线色猜。
- [ ] 电源电压、逻辑高电平、共同地及隐藏电源脚均已核对。
- [ ] 分清串联限流、上拉、下拉和分压，逐端点检查电阻接在哪里。
- [ ] 输入接输出：UART的TX到RX；I2C的SCL到SCL、SDA到SDA。
- [ ] 复位、启动模式、器件地址和接口模式满足要求。
- [ ] 固件中的引脚与接线相同，HEX路径存在，串口格式一致。
- [ ] 先验证一项；记录实际输出，再加入下一个器件。

## 八、这轮运行怎样验收

修好上拉后继续使用`oled_gpio_diag.hex`，PA1仍隔离；不要期待超声距离。先看BOOT行，再看ACK/屏幕文字，再看CMD与PA1高低一致切换。

若出现`screen_write=1,bus_error=0`且屏幕有可读文字并持续更新，才记OLED显示通过。若仍失败，保留完整BOOT和错误码以及修改后的接线截图，继续按总线、复位、模式和电源定位；不据本次发现预先断言黑屏已解决。
