# PA1慢速输出测试

日期：2026年10月14日。用户反馈按当前示波器配置运行仍是一条直线，15微秒触发是否出现尚未确认。

先停止仿真，将U1的Program File换为：

```text
D:\仿真创新大赛\sonar_edu\firmware\build\pa1_slow_diag.hex
```

现有电路暂时保留，终端仍为9600 8N1。先看终端和PA1引脚的红蓝逻辑颜色；20微秒时基不适合观察半秒电平保持，不需要继续调整示波器。如果愿意看慢波形，之后再切到200毫秒每格。

新程序仅启用TIM1延时、GPIO与USART1，明确关闭TIM2时钟，PA1分别保持高、低电平约500毫秒，PB0同步显示命令状态。串口发送还会增加少量周期时间。它比较BSRR高16位复位及BRR复位两种写法。

本轮只测试PA1输出与读回；长电平不是标准超声触发，不能用来验收距离。程序不输出S/status格式，预期如下：

```text
BOOT,PA1_SLOW_V01,TIM2=OFF,BAUD=9600
T,method=BSRR,cmd=1,pa1=1,pa0=0
T,method=BSRR,cmd=0,pa1=0,pa0=0
T,method=BRR,cmd=1,pa1=1,pa0=0
T,method=BRR,cmd=0,pa1=0,pa0=0
```

cmd是软件要求输出的状态，pa1是延时后读GPIOA_IDR得到的数字引脚状态。pa0受超声模块实际输出影响，上例的0仅为示意，本轮不要求pa0为固定值。PB0亮灭表示命令循环，不单独证明PA1状态。

- 两种方法的pa1都跟随cmd变1/0：支持普通GPIO可以切换；后续用关闭TIM2的15微秒触发测试，单独确认触发和回波。
- cmd变而pa1不变：检查GPIO输出路径和外部连接；需要再做断开TR模块输入后的隔离测试。
- 两种方法结果不同：保留完整输出，以便定位复位写法或模型行为差异。
- pa1读回变化但示波器始终平直：先确认示波器A连接到同一PA1网络，再检查通道与时基设置。

构建与HEX校验通过，镜像1056字节、SP=0x20002800，启动接口保留且无BKPT 0xAB。

## 已观察到的结果与隔离测试

用户运行截图显示BSRR和BRR两种方法均为cmd=1时pa1=1、cmd=0时pa1仍为1；pa0为0。TIM2已关闭，因此该结果不能仅归因于原双通道捕获配置。PA1读回未跟随低电平命令，尚未确定是外部网络拉高、模型接口还是GPIO输出的问题。

慢速测试在10微秒时基下显示平线本身不构成故障证据；本次判断依据是串口读回。

下一步停止仿真，另存一个隔离测试副本。断开PA1（芯片11脚）连出的全部外部绿色导线，让PA1不再与超声TR、示波器或任何供电网络连接。其他电路及当前pa1_slow_diag.hex保留，然后重新运行。

- 如果cmd=0时pa1恢复0、cmd=1时pa1为1，外部连接或负载影响了原测试，按模块与示波器逐项接回。
- 如果PA1完全悬空后仍一直读1，再检查GPIO寄存器读回与模型；此时才有依据将排查重点放到主控端。

该隔离测试已由用户执行，见下方实际结果。不能把连接外部电路时的常高结果等同于芯片损坏或软件跑飞。
