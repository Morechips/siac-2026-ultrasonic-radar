# 功能流程梳理（科教视角）

日期：2026-10-21。对应版本：`LM3S317_radar_v13_working.pdsprj` + `lm3s317_radar_v13.hex` + 网页 `showcase`。

---

## 一、三层流程

### 第 1 层：数据流（机器怎么跑）

```
超声模块 SRF04
    │ ① 触发 20µs
    ▼
LM3S317 ── ② 测回波脉宽 → 换算距离
    │
    ├─→ ③ 舵机转动 3°（每步 2~20 帧 × 20ms）
    │
    ├─→ ④ 记录：I2C 写入 24C02C（每 8 字节一页，环形 31 条）
    │
    └─→ ⑤ 上报：UART 9600，六字段 SCAN 帧（限 80ms 一帧）
                │
                ▼
        COMPIM → COM32 → com0com → COM33
                │
                ▼
        网页：解析 → 画点 → 显示距离/角度/状态
```

**一个循环 = 80ms 一次上报**；扫完 0°~180° 共 61 点，按速度档位不同需要 2.44~24.4 秒。

### 第 2 层：课堂流程（老师怎么上）

```
【课前 5 分钟】
  运行仿真 → 终端出现 INFO,EEPROM_SELFTEST_OK
  网页连 COM33 → 点「清空结果」
        │
        ▼
【0-5 min｜导入】
  提问：蒙上眼睛，怎么知道前面有没有东西？
  引出：声音发出去，碰到东西会弹回来
        │
        ▼
【5-12 min｜演示一次测量】
  打开网页「分步教学」，逐帧看四个瞬间：
  ① 转向定位 → ② 发射声波 → ③ 接收回波 → ④ 更新距离
        │
        ▼
【12-20 min｜任务 1：远近与回声】
  老师改模块距离 140 → 100 → 50 cm
  学生：先写预测 → 再看读数 → 填记录单
  结论：距离越远，回声往返时间越长
        │
        ▼
【20-28 min｜任务 2：方向与扫描】
  观察扇形雷达上点是怎么一个个出现的
  学生指认三个点分别在左 / 前 / 右
  结论：要描述障碍，需要「方向 + 距离」
        │
        ▼
【28-34 min｜任务 3：测不到怎么办】
  制造一次超时（把模块距离改到超出量程，或暂停仿真）
  观察状态显示「无可靠量程内测量 / 数据已超时」
  结论：不知道 ≠ 安全
        │
        ▼
【34-40 min｜复盘与导出】
  按按键3 回放刚记录的数据（网页显示为历史点迹）
  网页记录台导出 CSV，或用纸质记录单
  每组说一条发现
```

### 第 3 层：学生闭环（怎么学）

```
   预测 ──→ 操作 ──→ 观察 ──→ 记录 ──→ 解释
    │        │         │         │         │
    │        │         │         │         └─ 结论必须引用自己的数据
    │        │         │         └─ 网页记录台 / 纸质记录单
    │        │         └─ 读数、角度、状态、报警
    │        └─ 老师改距离 / 学生按键调速
    └─ 先写下来，错了也没关系，要写理由
```

## 二、老师手里的三个「旋钮」

| 旋钮 | 怎么操作 | 教学用途 |
|---|---|---|
| **目标距离** | 点 Proteus 里超声模块右侧的上下箭头（如 140→50） | 任务 1：远近与回声 |
| **扫描速度** | 按住模块的按键2（10 档，40~400ms/步） | 讲"扫得快 vs 扫得细" |
| **报警阈值** | 网页「连接与数据」→ 距离报警 → 改数字 | 讲"多近算近"、阈值判断 |

三个旋钮互相独立，可以单独演示，也可以组合（例如：慢速扫描 + 低阈值报警）。

## 三、功能与教学环节的对应

| 教学环节 | 用到的功能 | 学生看到什么 |
|---|---|---|
| 导入 | 网页分步教学（四阶段动画） | 一次测量是怎么发生的 |
| 任务 1 | 超声测距 + 网页「当前测距」 | 读数随设定距离变化 |
| 任务 2 | 舵机旋转扫描 + 扇形雷达 | 点迹按角度一个个出现 |
| 任务 3 | 超时/超量程状态显示 | "无可靠量程内测量" |
| 记录 | 网页实验记录台（预测 + 记录 + 200 条上限） | 自己的预测与观察并排 |
| 复盘 | 按键3 回放 EEPROM 记录 | 历史点迹（与实时区分） |
| 课后 | CSV 导出 | 可带走的原始数据 |
| 报警演示 | 距离报警开关 + 阈值 | 距离小于阈值时状态变「近距报警」 |

## 四、三种典型演示脚本

### A. 5 分钟快演（走廊展示 / 答辩开头）

1. 运行 → 网页出图（30 秒）
2. 改距离 140→50 → 读数跟着变（1 分钟）
3. 按按键2 提速 → 扫得更快（30 秒）
4. 改阈值到 60cm → 50cm 时立刻报警（1 分钟）
5. 按按键3 回放（1 分钟）

### B. 40 分钟完整课

见第 2 层课堂流程。

### C. 故障演示（讲"测量不可靠"）

1. 把模块距离改到 260cm（超出 250cm 量程）→ 显示"无可靠量程内测量"
2. 暂停仿真 → 网页 2 秒后显示"数据已超时"
3. 讨论：这两种"没数据"分别意味着什么

## 五、不建议现在再加的功能

| 想法 | 结论 |
|---|---|
| 单次测量模式（按一下测一次） | 教学上最直观，但要改固件 + 测试，**列入后续** |
| 网页显示当前速度档位 | 纯展示，无评分价值，**不做** |
| 多目标跟踪 / 建图 | 硬件条件不具备，**不做** |
| 电位器无级调速 | 需验证 ADC，**列入后续** |

理由：当前三条验证链（采集—上报—显示、存储—回放、按键—交互）都已打通，任何改动都可能破坏已验证状态。
