# 课程包：超声雷达实验课

适用：小学高年级（5~6 年级）科学课，或初中低年级物理/信息科技课
课时：40 分钟（可拆成两节 20 分钟）
设备：一台运行 Proteus + 网页的电脑（教师机）＋ 可投屏；学生每 3~4 人一组共用

---

## 一、教学目标

| 目标 | 达成标志 |
|---|---|
| 1. 知道"回声"可以用来测距离 | 能说出"声音发出去、碰到东西弹回来，来回一趟需要时间" |
| 2. 知道"方向"需要用转动来获得 | 能指出"探头转到哪个角度，测到的就是那个方向" |
| 3. 知道"测不到"也是一种信息 | 能说出"没有读数不等于前面一定安全" |

---

## 二、三张学生任务卡

### 任务卡 1：远近与回声

**你会用到**：网页上的"当前测距"和"扫描轨迹"。

**做一做**

1. 老师把目标距离先后设为几个不同的值（如 140cm、100cm、50cm）。
2. 每一档，**先写下你的预测**，再看屏幕上的读数。
3. 把结果填进记录单。

**想一想**

- 距离变大时，回声回来的时间变**长**还是**短**？
- 为什么？

> 提示（教师口径）：声音跑一个来回，距离越远，来回时间越长。

---

### 任务卡 2：方向与扫描

**你会用到**：网页上的扇形雷达和"探头角度"。

**做一做**

1. 观察探头转动时，屏幕上的点是怎么一个一个出现的。
2. 记录三个不同角度上的读数。
3. 说出这三个点分别在**左边、前方还是右边**。

**想一想**

- 如果探头**不转**，只知道距离，能说出东西在哪边吗？
- 要描述一个障碍，为什么需要"方向 + 距离"两件事？

---

### 任务卡 3：测不到怎么办

**你会用到**：网页上的"探测状态"和记录台。

**做一做**

1. 观察出现"超时 / 无可靠量程内测量"时的界面。
2. 记录一次**没有读数**的情况。
3. 和一次**有读数**的情况对比。

**想一想**

- "测不到"能不能理解成"前面是空的、安全的"？
- 如果机器没测到，你会怎么做？

> 提示（教师口径）：测不到可能是太远、太近、角度不对、物体太软。**不知道 ≠ 安全**。

## 四、教师指引

### 课前准备（5 分钟）

1. 打开 Proteus 工程 `LM3S317_radar_v13_working.pdsprj`，运行仿真
2. 终端确认出现 `INFO,EEPROM_SELFTEST_OK`（表示整套功能正常）
3. 启动网页 `showcase\start.cmd`，Chrome 打开 `http://localhost:5173/`
4. 网页右上角"连接与数据"→ 浏览器串口 → 选 **COM33**、9600 → 连接
5. 网页点"清空结果"，确保从干净画面开始

### 40 分钟课时安排

| 时段 | 内容 | 教师动作 |
|---|---|---|
| 0-5 min | 导入：提问"蒙上眼睛怎么知道前面有东西？" | 引出回声 |
| 5-12 min | 演示：一次完整测量（转向 → 发射 → 接收 → 更新） | 用网页"分步教学"逐帧讲解 |
| 12-20 min | **任务卡 1**：远近与回声 | 依次改目标距离，学生先预测再观察 |
| 20-28 min | **任务卡 2**：方向与扫描 | 让学生指认左/前/右 |
| 28-34 min | **任务卡 3**：测不到怎么办 | 制造一次超时，讨论"不知道≠安全" |
| 34-40 min | 汇报：每组说一条发现 | 收记录单，点出"预测—观察—解释"的方法 |

### 演示操作要点

| 想演示 | 怎么操作 |
|---|---|
| 距离变化 | 点 Proteus 里超声模块右侧的**上下箭头**改设定值（如 140 → 50） |
| 扫得快/慢 | 按住模块的**按键2**，`INFO,SPEED` 会连续变化 |
| 暂停/继续 | 按**按键1** |
| 回放刚才的记录 | 按**按键3**，终端会逐条打出 `LOG,...` |

### 常见问题

| 现象 | 处理 |
|---|---|
| 网页不动 | 仿真是"停止"状态，或网页的"暂停展示"被点过 |
| 网页显示"数据已超时" | 仿真停了；重新运行并重新连接串口 |
| 距离一直是同一个数 | 正常：仿真中距离由模块设定值决定，需手动改 |
| 按键没反应 | `BUTTON` 是点一下保持按下，需要再点一次松开 |

### 评价量规（三条，各 0~2 分）

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 观察准确性 | 记录与屏幕明显不符 | 大部分相符 | 与屏幕完全一致，含角度和距离 |
| 预测有依据 | 没有预测 | 有预测但无理由 | 预测写明了理由 |
| 结论对应数据 | 结论与数据无关 | 结论笼统 | 结论能引用自己的具体数据 |

### 安全与边界提示（务必说明）

- 本作品是**实验演示**，不是安全设备，不能用于真实的安全判断
- 仿真中"距离"是老师设定的，**不是真实的声学测量**
- 真实传感器会因为材质、角度、噪声而测不准，这也是课程要讨论的内容之一

## 五、课程包与作品的对应关系

| 教学环节 | 用到作品的哪个功能 |
|---|---|
| 任务卡 1 远近与回声 | 超声测距 + 网页"当前测距" |
| 任务卡 2 方向与扫描 | 舵机旋转扫描 + 网页扇形雷达 |
| 任务卡 3 测不到怎么办 | 超时/超量程状态显示 |
| 课堂记录与导出 | 网页实验记录台 + CSV 导出 |
| 课后回看 | 按键3 回放 EEPROM 中的 31 条记录 |

> 说明：网页端的预测、记录、CSV 导出由网页模块提供；纸质记录单用于没有电脑的课堂，两者内容一一对应。
