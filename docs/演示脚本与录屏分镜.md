## 一、录屏前准备

### 窗口布局（三块，1080p 下同屏可见）

| 区域 | 内容 | 位置 |
|---|---|---|
| 左 | Proteus 原理图（缩放到能看清 MCU、模块、EEPROM、COMPIM） | 左侧 50% |

### 检查清单（录制前逐项确认）

- [ ] Proteus 工程是 `LM3S317_radar_v12_working.pdsprj`，Program File 指向 `lm3s317_radar_v12.hex`
- [ ] 超声模块 **VCC = 3.3V**（不是 5V）
- [ ] SDA 有 10k 上拉到 3.3V
- [ ] COMPIM：COM32、9600、`P_HARDFLOW=0`、`V_HARDFLOW=0`，PA1 接 **TXD**
- [ ] 网页已在 `http://localhost:5173/` 打开，串口连 COM33、9600
- [ ] 终端里已确认 `INFO,EEPROM_SELFTEST_OK`
- [ ] 模块的 Distance 属性先设成 **71cm**（开场用）
- [ ] 关闭无关弹窗、微信、通知，任务栏自动隐藏
- [ ] 录制：1080p / 30fps / 系统声音可选

## 二、分镜脚本（总长约 3 分 30 秒）

| # | 时长 | 画面 | 操作 | 旁白要点 |
|---|---|---|---|---|
| 1 | 0:00-0:20 | Proteus 原理图全景 | 鼠标缓慢划过 MCU、超声模块、舵机、EEPROM、COMPIM | 系统由 Cortex-M3 主控、超声测距、舵机扫描、I2C 存储、串口与网页组成 |
| 2 | 0:20-0:45 | 网页雷达全屏 | 点击"连接与数据"→选 COM33→连接 | 上位机通过虚拟串口接收数据，实时重建扫描结果 |
| 3 | 0:45-1:15 | 原理图 + 终端 | 点击运行；终端出现 `BOOT`、`INFO,EEPROM_SELFTEST_OK`、连续 `SCAN` | 主控每 80ms 完成一个角度的触发、测距与上报 |
| 4 | 1:15-1:45 | 网页雷达 | 观察扫描线与距离读数 | 角度 3° 一步往返扫描，距离以毫米上报、界面显示厘米 |
| 5 | 1:45-2:15 | 原理图（放大超声模块） | 点击模块右侧上下箭头，把 Distance 从 71 改到 40 | **受控输入演示**：改变目标距离，系统应跟随变化 |
| 6 | 2:15-2:35 | 网页 + 终端 | 继续观察，距离读数随之变化 | 读数随之下降，说明测量链路是真实的，不是画面特效 |
| 7 | 2:35-2:55 | 终端 | 按**按键1**（PB1）约 0.5 秒 → `INFO,STOP`；再按 → `INFO,RUN` | 本地按键可启停扫描 |

| 9 | 3:15-3:30 | 原理图 + 结束画面 | 停止仿真，展示工程结构 | 全部功能在 Proteus 中完成，主控为 Cortex-M3 |

## 三、旁白文字稿（可直接照读）

> 本作品是基于 Cortex-M3 微控制器的超声旋转扫描雷达实验系统，全部功能在 Proteus 中仿真运行。
>
> 系统由五部分组成：舵机带动超声探头旋转扫描；主控负责触发、计时与调度；测量结果按角度打包，通过串口上报；本地 I2C EEPROM 保存最近 31 条记录；上位机网页把数据还原成雷达图。
>
> 现在我们启动仿真。终端先输出开机信息和 EEPROM 自检结果，随后每个扫描角度输出一行测量数据。
>
> 网页通过虚拟串口接收这些数据，实时重建扫描结果。可以看到探头在 0 到 180 度之间往返，每步 3 度。
>
> 由于仿真环境中的超声模型采用固定设定距离，我们在运行中直接改变它的距离设定值，用受控输入来验证整条测量链路。可以看到，读数随设定值变化，说明数据是真实测量得到的。
>
> 按下本地按键可以暂停扫描；再按一次恢复。
>
> 扫描过程中，每一次测量都会写入 I2C EEPROM。按下第二个按键，就可以把历史记录回放出来，终端会逐条输出存储的角度与距离。
>
> 以上就是这个系统的完整演示：数据采集、控制、存储、输出与人机交互界面，全部在 Cortex-M3 上实现。

## 五、常见问题

| 问题 | 处理 |
|---|---|
| 网页画面不动 | 仿真是"停止"状态；或页面"暂停展示"被点过 |
| 终端没数据 | Program File 是否指到 v12；COMPIM 是否接 TXD |
| 距离一直是 71cm | 正常，模型距离是设定值；按分镜 5 手动改 |
| 回放没有 LOG 行 | 先确认按键2 真的按下（按住 0.5 秒）；确认 SDA 有上拉 |
| 画面太小看不清 | 把 Proteus 缩放固定，终端字号调大，或分段录制后剪辑 |
