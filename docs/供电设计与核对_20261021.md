# LM3S317教育超声模块：供电设计与核对

日期：2026-10-21。**本文件为接线设计建议，未修改Proteus原理图，未执行新供电电路验收。** 本轮采用外部稳压5V输入，配逻辑稳压和舵机支路；器件型号待本机模型与负载规格核对后确定。

后续已形成[具体器件、引脚与网名的实施候选](供电模块实施方案_20261021.md)，包括本机LM1117库条目和电容/压降要求；仍未放置、运行模型或定型采购。本文件保留原则与验收框架。

## 1. 最小连接表

建议网络名统一使用 `EXT_5V`、`SYS_5V`、`+5V_SERVO`、`LOGIC_3V3`、`GND`，避免将相同的VCC标签误当成不同电压。当前Proteus默认VCC/VDD网络为3.3V，逻辑和超声模型依赖这一配置；**不要将全局VCC/VDD直接改为5V**。新增舵机5V支路使用独立网名，并逐项核对隐藏电源引脚的网络映射。

| 部分 | 建议连接 | 接线前必须核对 |
|---|---|---|
| 输入J1 | 外部5V正极进入输入保护及SW1，输出命名SYS_5V；负极接GND | 接口极性、保护压降、电流额定值；优先使用已有合规5V输出模块 |
| 输入保护 | 在输入链路配置适合接口的限流/过流保护；可反接的接口加入相应反接保护 | 保护件及开关应承受舵机启动电流；保护后电压仍满足负载 |
| 电源指示 | SYS_5V经限流电阻和LED接GND | 按LED参数计算限流电阻，指示的是开关后的电源 |
| 逻辑稳压U_PWR（占位编号） | VIN接SYS_5V，VOUT接LOGIC_3V3，GND接公共地；按型号接EN等引脚 | 本机有可运行模型；输入范围、压差、电流、散热及电容要求满足设计；已有U3为EEPROM，新增器件另行编号 |
| MCU供电 | 所有VDD接LOGIC_3V3，所有GND接公共地；各电源脚附近配置去耦 | 实际封装与Proteus隐藏电源脚/网络归属一致 |
| MCU内部LDO | LDO输出脚仅按手册接专用滤波电容到GND，不接到外部3.3V网 | 原厂表19-3给出外部滤波电容1–3µF；不得当作外设供电输出 |
| EEPROM | VCC接LOGIC_3V3，VSS接GND；SCL/SDA上拉到LOGIC_3V3 | 本机24C02C型号、WP与地址脚配置、上拉值和去耦 |
| 按键 | 输入脚经外部上拉接LOGIC_3V3，按钮按下接GND | 与最终固件的PB1/PB5或备选引脚一致；松开高、按下低 |
| 本机超声模型 | 保留当前已通过的3.3V供电网络，TR/ECHO信号沿已通过接线 | 不因新增5V输入就将模型VCC改成5V |
| 舵机支路 | SYS_5V独立支路命名+5V_SERVO，连接舵机电源，回流回到电源入口公共地；PWM沿原接线 | 只有所选舵机允许5V时才这样接；核对隐藏电源映射，支路滤波与储能电容待负载核算 |

LM3S317原厂手册给出VDD推荐3.0–3.6V，标称3.3V。表17-2中的VDD/GND/LDO脚位应与最终封装核对；对应手册48引脚器件，LDO为6脚，VDD为7/15/23/32脚，GND为8/16/24/31脚。电容和电源范围依据[原厂手册，印刷386–393页](https://www.keil.com/dd/docs/datashts/luminary/lm3s317.pdf)。

去耦可先按每个VDD附近配置0.1µF陶瓷电容准备BOM，这是板级设计初选；稳压器输入/输出电容和舵机支路储能值须按最终器件手册及验证确定，不统一套用一个容量。

若逻辑稳压器为线性稳压器，可用 `P_reg ≈ (V_IN − 3.3V) × I_logic` 估算发热，输入电流预算近似为 `I_servo_peak + I_logic + I_other`，另考虑静态电流及余量。若改用开关稳压器，应按效率和功率换算输入电流，再复核模型和纹波。电压须使用输入保护后的最差值，不能只取电源标称值。

## 3. 仿真与实物适配

当前工程的超声模型按已通过配置使用3.3V。厂家SRF04实物标称5V供电、典型电流30mA；实际采购HC-SR04或其他模块时，应以该实物的可靠资料重新核对。[SRF04规格](https://www.robot-electronics.co.uk/srf04.html)

ECHO电平是否需转换要按最终MCU/管脚确认。LM3S317原厂手册GPIO章节标明GPIO支持5V容忍，不能笼统声称当前PA3必然不耐5V；迁移到其他3.3V主控时应重新核对。[原厂手册，印刷399页](https://www.keil.com/dd/docs/datashts/luminary/lm3s317.pdf)

MOTOR-PWMSERVO若只表现CTRL行为、没有供电负载端，转动动画不能证明供电电流和浪涌能力。图上仍需表达实物供电支路，电流能力列为计算和待实物验证。稳压模型也不能替代实物温升测试。
