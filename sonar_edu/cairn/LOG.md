# 项目日志

## 2026-10-21 01:31：串口链路打通（Proteus → COMPIM → com0com → COM33 实测 132 行）

- **com0com 3.0.0.0 官方签名版**已安装；安装时自动建了两对端口，第二对已是 COM 号：`com0com11=COM33`、`com0com21=COM32`。用两个 SerialPort 互发数据验证双向通。
- **COMPIM 不在仪器列表里**（本机 8.9 的列表只有 13 个仪器，无 COMPIM）。解决办法：从官方示例 `DATA\SAMPLES\Interactive Simulation\COMPIM Demo\TERMECHO.pdsprj` 里 Ctrl+C 复制元件过来，粘贴到自己工程即可，属性完整可用。
- **关键坑1：引脚方向与 Virtual Terminal 相反。** COMPIM 的引脚是按 MCU 侧命名的，**MCU TX 要接 COMPIM 的 TXD（3脚）**，接 RXD 收不到任何数据。
- **关键坑2：默认开启硬件流控。** 官方示例属性为 `{P_HARDFLOW=1}{V_HARDFLOW=1}`，CTS 悬空时数据被压住不发；须改为 `P_HARDFLOW=0`、`V_HARDFLOW=0`（在元件属性里勾"使用文本方式编辑所有属性"改，比下拉框好找）。
- **关键坑3：Physical port 下拉框只列 COM1~COM4**，手打 `COM32` 是有效的，能正常打开。
- 实测：仿真运行中，COM32 被 COMPIM 占用，COM33 在 5 秒内收到 3573 字节 / 132 行，全部为合法 `SCAN,seq,angle,710,OK,PROTEUS`，角度 3° 递增。仿真速度约为实时 2 倍。
- 待做：网页端 Web Serial 选 COM33/9600 连接；按键；EEPROM 回放验证；材料。
- 入口：[串口联调步骤](../showcase/串口联调步骤_20261021.md)。

## 2026-10-21 凌晨：根因确认——超声模型必须3.3V供电，V10实测通过

- **关键发现**：本机 HCSR04/SRF04 模型接 **5V 时不响应触发**（触发脚读数正常、ECHO 全程不动），接 **3.3V 立即正常测距**。这一条同时解释了 10-18 起 F103 与 LM3S317 两条线"触发正常、无回波"的同一症状；交接文档里"空白供电端子改名 5V 后有效距离未恢复"就是同一个原因，之前被当成偶发。
- 用户把模块 VCC 从 VDD5V 改到默认电源网（3.3V）后，V10 立即输出 `SCAN,0,93,710,OK,PROTEUS` 连续有效行，角度按 3° 递增。
- 顺带修复：按键去抖原逻辑在"引脚从开机就是 0"时会误触发一次，导致一开机就打 `INFO,STOP`；改为"必须先见过高电平才允许触发"后消失。v10r1 已实测无此现象。
- 边界：读数恒为 710mm，因为模块 Distance 属性就是 71cm，模型不模拟空间物体；这不代表空间建图能力。演示时可用模块右侧上下箭头在运行中改距离验证跟随。
- 待办：①两按键接线验收 ②AT24C02(I2C)存扫描记录 ③COMPIM+虚拟串口对+网页联调。
- 入口：[V10说明](../proteus/current_test/lm3s317_radar_v10.md)。OLED 未参与，V04/V08 基线未改动。

## 2026-10-20 夜：放弃OLED主链路，改为 LM3S317单芯＋网页显示，V10核心固件完成

- 用户提出"去掉OLED、直接串口给网页"；确认AVR Arduino不合规（本科要求Cortex-M3），改用 LM3S317——它在超声、舵机、串口、GPIO输入四项上都已单独实测通过，唯一卡死项正是OLED。
- 今晚在F103方向的尝试全部归档为失败诊断：V01自动扫描18种触发组合（`TH=1/TL=0`证明MCU驱动正常）、V03端口监视（PA/PB共32脚零活动）、慢速方波V04。结论：F103侧干净，HCSR04模型在此电路下不响应触发；不继续投入。
- 同时确认两件与固件无关的环境事实：电压表悬空会造成 `[SPICE] {null}` 使模拟域无法启动；`CM3_STM32.DLL access violation` 重启Proteus即可消失（与10-14的MSVCR90异常同类）。
- 新固件 `lm3s317_radar_v10.c`（1628字节）：超声测量序列原样搬用 probe；PB0软件PWM 50Hz扫描3°/80ms；UART0 9600非阻塞环缓输出 `SCAN,seq,angle,mm,status,PROTEUS`；PB1/PB5按键带电平锁存去抖（无按键时不会误触发启动/停止）；**完全不访问OLED**。
- 构建：ARM GCC（STM32CubeCLT），-Wall -Wextra -Werror 通过，HEX/SP/Reset校验通过。
- 下一步顺序：①V10在V04标签工程里跑通 ②接两按键 ③AT24C02(I2C)存扫描记录 ④COMPIM+虚拟串口对+网页联调。风险提示已写入文档：模型距离恒为固定SETPOINT，不随角度变化。
- 入口：[V10说明](../proteus/current_test/lm3s317_radar_v10.md)。原V04/V08固件与工程未改动。
