## 步骤

### 1. 安装 com0com

安装包已下载并校验为官方签名版：

```
tools_download\com0com\Setup_com0com_v3.0.0.0_W7_x64_signed.exe
```

需要管理员权限，右键"以管理员身份运行"，全程默认下一步。

### 2. 建立 COM 端口对

**已完成。** com0com 3.0.0.0 安装后自动建立两对端口，其中第二对已经是 COM 号：

| 设备名 | 端口 | 用途 |
|---|---|---|
| `com0com11` | **COM33** | 网页 Web Serial 用这一端 |
| `com0com21` | **COM32** | Proteus COMPIM 用这一端 |
| `com0com10` | CNCA0 | 另一对，未使用 |
| `com0com20` | CNCB0 | 另一对，未使用 |

已用两个 SerialPort 互发 `PING-FROM-COM32` / `PING-FROM-COM33` 验证 **双向互通正常**（2026-10-21 实测）。

如需查看或修改端口配置：开始菜单 → com0com 文件夹 → **Setup**（即 `C:\Program Files (x86)\com0com\setupg.exe`，需要管理员权限）。

### 3. Proteus 里加 COMPIM

1. 停止仿真
2. **Virtual Terminal 可以保留**（它只是另一个接收端，MCU 的 TX 同时喂给两个接收端没问题），调试时还能看原始数据
3. 从虚拟仪器里选 **COMPIM** 放到图里
4. 双击 COMPIM 设置：
   - **Physical port** = `COM32`，Physical baud rate = `9600`
   - **Virtual baud rate** = `9600`
   - 数据位 8、无校验、1 停止位、无流控
5. 接线：**MCU PA1（TX，脚 18）→ COMPIM 的 RXD**；GND 与 COMPIM 的 GND 共地
   - COMPIM 的引脚是从 PC 侧命名的，所以 MCU 的 TX 要接 COMPIM 的 **RXD**

### 4. 网页连接

1. 双击 `showcase\start.cmd`，等服务起来
2. 用 **Chrome 或 Edge** 打开 `http://localhost:5173/`（必须是 localhost，Web Serial 只在安全上下文可用）
3. 页面右上角"连接与数据" → "浏览器串口" → 选 **COM21**、9600 → 连接
4. 点运行仿真

### 5. 验收

- 网页雷达上出现扫描线，角度与终端里的 `SCAN` 行一致
- 距离显示 71.0cm 左右（模型 SETPOINT=71cm）
- 终端与网页同时更新，互不干扰

## 故障分流

| 现象 | 先查 |
|---|---|
| 网页连上但画面不动 | **先确认仿真是"运行"而不是"暂停"**（Proteus 暂停后 COMPIM 不再送数据，网页停在最后一帧）。其次检查页面上的"暂停展示"按钮是否被点过 |
| Web Serial 里看不到 COM21 | com0com 没改名成功；或用设备管理器确认端口名 |
| 选了端口但连不上（端口被占用） | Proteus 是否也在用同一个口；两端必须是**不同**的 COM 号 |
| 网页连上但没数据 | COMPIM 的 Physical/Virtual baud 是否都是 9600；MCU TX 是否接到 COMPIM 的 RXD（不是 TXD） |
| 数据是乱码 | 波特率不匹配（9600）；或 MCU 时钟不是 8MHz |
| 网页报"未知数据格式" | 固件是否输出了 6 字段短帧；16 列 CSV 页面不认 |
| Proteus 报端口打开失败 | 先关网页连接再启动仿真，或反之；同一端口不能被两个进程同时占用 |

## 备选方案

若 com0com 装不上或权限受限：

1. **VSPE**：安装包已在 `sonar_edu\tools\vspe\1.5.8.489\SetupVSPE_64.msi`，但免费版需要邮件申请 license。
2. **录播兜底**：把终端输出复制下来，用网页的"输入测量字符串"模式演示。适合录制视频，但**不能宣称实时联动**，说明书须注明。
